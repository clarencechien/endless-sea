# Endless Sea

一架小飛機，一片無邊的海。瀏覽器中的程序化海洋飛行體驗。

## 開發

需要 Node.js 22.12+（本環境使用 Node.js 24）。

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

開發伺服器預設監聽 5173。需要支援 WebGL 2 且開啟硬體加速的現代瀏覽器。沒有後端、API 金鑰或外部模型依賴。所有視覺資產皆在本地生成，字型使用系統字型，不需外部 CDN。

## 飛行

點「開始飛行」後，以 W/S 俯衝與爬升、A/D 轉向、方向鍵上下調整油門。手動操作會解除自動巡航；P 切換巡航、R 重設、H 隱藏或恢復介面。手機點「開始飛行」時優先啟用體感，沒有方向按鈕。右側四個圓鈕切換晨光、夕照、暮色與星夜；設定可調整風力與渲染精細度。環境音需自行開啟。

## 畫面技術與範圍

Three.js 負責圖形管線與程序化小飛機模型；自訂 GLSL 著色器渲染無限海面。多尺度波形、解析波面法線、Fresnel 反射、GGX 太陽高光、遠距霧化與程序化雲層營造光影。此版本使用 WebGL 2 以支援更多裝置；海浪是視覺近似，並非 FFT 流體模擬。飛行採簡化運動模型，第一章最低高度 18 公尺，無失速模擬。第一章是海與天空，第二章是六座程序化山島，包含沙岸、淺海色帶與沿岸浪花。飛機會在地形上方保持至少 24 公尺高度；這是防穿越輔助，並非碰撞物理。效能取決於 GPU 與畫面解析度。

`src/ocean.js`：海天著色器；`src/plane.js`：飛機幾何；`src/flight.js`：可測試的飛行狀態；`src/main.js`：場景、相機與互動。

瀏覽器功能檢查：`npm run test:browser`。預先啟動開發伺服器，並安裝 Chromium；可用 `CHROMIUM_PATH` 指定其執行檔。測試會檢查 GPU 渲染、飛行操作、畫面設定、音效、指南與手機體感／巡航切換。

## GitHub Pages

推送到 `main` 後，`.github/workflows/pages.yml` 會執行測試、建置並部署到 GitHub Pages。首次部署若無法自動啟用 Pages，請到 GitHub 專案 **Settings → Pages → Build and deployment → Source** 選擇 **GitHub Actions**，再重新執行部署 workflow。

預期網址：https://clarencechien.github.io/endless-sea/

Vite 使用相對資源路徑，支援 Pages 的專案子目錄。產出可用 `npm run preview` 在本機檢查。


## 章節、配樂與全螢幕

上方選單可切換五個章節，切換時回到該章起始航線。每章停留 24 分鐘自動前往下一章，第五章完成後回到第一章；手動切章會重新計算該章的 24 分鐘。R 只重設航線，不重設章節間隔。地形以週期區塊沿航線重複，並非每區都獨一無二的無限地圖。

點喇叭啟動聲音。原創配樂以 68 BPM、MIDI 音高／力度／節拍資料編排，由 Web Audio 合成柔和的電鋼琴與長音；五章使用不同和聲與旋律。設定內可下載標準 MIDI Format 0 檔案（480 ticks/quarter，電鋼琴與暖音色 pad 音軌通道），可交給 DAW 或 MIDI 播放器重新配器；網頁無須 MIDI 硬體或外部音源。風聲與潮汐採獨立立體聲噪音、濾波及慢速音量調變，引擎頻率隨速度改變。配樂、引擎、風與海各有獨立音量；背景分頁會暫停音訊。

右上角全螢幕按鈕可進入／退出全螢幕，桌面也可用 Esc 退出。瀏覽器不支援 Fullscreen API 時會停用按鈕；H 隱藏介面仍可使用。

新增模組：`src/score.js` 樂譜與 MIDI 匯出、`src/audio.js` 音訊合成與混音、`src/terrain.js` 地形及安全高度、`src/islands.js` 島嶼網格與材質。


## 體感與流動的時間

手機點「開始飛行」時會優先啟用體感，首次有效讀值將目前握姿設為中立點。左右傾斜轉向，前後傾斜控制升降；包含 3 度死區、平滑處理、橫直向轉換與重新校準。需要 HTTPS 和可用的方向感測器；iOS 會在點擊開始飛行時請求權限。拒絕權限、不支援感測器或未收到資料時，會保留自動巡航。離開分頁或切換章節會在恢復時重新校準。開啟自動巡航後會忽略體感輸入，不會因手機晃動而解除。關閉巡航時，以目前握姿重新校準並恢復體感。設定仍可關閉、重啟或重新校準體感。

晝夜循環以頁面前景的實際經過時間計算，60 秒走過 1 個遊戲小時，1440 秒完成 24 小時；低幀率不會放慢天空時間。日光、夕照、星空與月光會連續變化。時刻圓鈕可跳至晨光、夕照、藍調或星夜，之後繼續流動。切換章節或重設航線不會清除發呆計數。

發呆計數使用與配樂相同的每分鐘 68 拍，靜音時仍累計；播放配樂時會對齊此節拍時鐘。分頁切到背景時，晝夜、計數與音訊一起暫停。計數限本次頁面工作階段，重新載入即歸零。

測試包含 MIDI 檔案結構、地形淨空、體感方向映射、晝夜速度、四個獨立音軌的實際訊號、全螢幕與瀏覽器模擬感測事件。模擬測試不等於實機 iOS／Android 感測器驗收。


## 五章的長途旅程

| 章節 | 風景 | 配樂方向 |
| --- | --- | --- |
| 01 海與天空 | 遠洋、海天交界 | 溫暖的長音與輕柔琶音 |
| 02 海島 | 青山、沙岸、淺海 | 明亮的和聲與流動旋律 |
| 03 峽灣回聲 | 高聳岩壁與狹長水道 | 低音域、空曠的小調 |
| 04 極地漂流 | 平頂冰島、裂紋與冷藍海面 | 高音域、稀疏的冰晶音符 |
| 05 火山餘燼 | 黑色火山錐、凹陷火口與發光紋理 | 深沉和聲與緩慢脈動 |

一輪共 120 分鐘。每章 24 分鐘等於 1,632 個 68 BPM 節拍；節拍累計與晝夜時鐘跨章保留。手動調整天空時刻不影響章節進度。新章從起始航線進入並顯示章節提示；切換時釋放舊地形的 GPU 資源。背景分頁不累計章節時間。

`npm run test:journey` 使用 Playwright 注入的加速時鐘驗證全部五章自動切換、循環、手動切章間隔、節拍連續與地形資源數量；需先建置並在 5174 啟動 preview，或以 APP_URL 指定伺服器。這是加速的瀏覽器測試，不是實際持續兩小時的效能測試。


節拍顯示採至少四位固定寬度數字；只有改變的位數輕柔向上滾動，9→0 連續進位。支援 prefers-reduced-motion，停用動畫時直接呈現正確數值；螢幕閱讀器取得目前數值，不逐拍公告。`APP_URL=http://127.0.0.1:5174 node tests/counter-browser.mjs` 驗證進位、無動畫偏好與位數擴充。主畫面只保留必要控制與短句，飛行提示數秒後淡出。


飛機外觀為暖白色摺紙滑翔機，包含有厚度的紙邊、中央折脊、細摺線、淡金色小星星與輕微翼面起伏。紙張顆粒由本地程序生成，無需外部模型或貼圖；飛行操控與原有音效設定維持相同。


畫布使用動態視窗高度與 viewport-fit=cover 鋪滿可用畫面，會隨手機工具列、旋轉及全螢幕狀態重新調整渲染尺寸；控制項避開瀏海與手勢安全區。高度、航向、空速共用雙向連續滾動的數字輪，航向跨越 359°／000° 也維持短距離轉動，並支援減少動態效果。儀表數值以約 0.22 秒平滑跟隨飛行狀態。`APP_URL=http://127.0.0.1:5174 node tests/instruments-browser.mjs` 驗證滿版尺寸、橫直向、控制項邊界與儀表滾動。瀏覽器工具列的隱藏仍由瀏覽器決定，可用右上角全螢幕按鈕進一步展開。
